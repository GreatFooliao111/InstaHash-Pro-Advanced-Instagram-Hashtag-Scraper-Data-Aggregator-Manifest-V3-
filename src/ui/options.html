Architecture & Best Practices

🏗️ Manifest V3 Compliance

  • No infinite loops in background: Scrolling logic runs in Content Script, not Service Worker
  • State management: Uses chrome.storage.session for ephemeral state, chrome.storage.local for persistence
  • Offscreen documents: Heavy CSV/JSON export operations run in isolated offscreen context

🌐 Network Interception

  • Main World injection: Fetch/XHR override runs in MAIN world (not isolated content script world)
  • Dynamic endpoint detection: Uses regex patterns instead of hardcoded URLs to handle API changes
  • Structural parsing: Identifies hashtag data by JSON structure (edge_hashtag_to_media) not URL paths

💾 Database & Deduplication

  • IndexedDB with idb: Promise-based wrapper prevents transaction errors
  • Shortcode as primary key: Ensures 100% deduplication at database level
  • found_in_hashtags array: Tracks which hashtags each post appeared in

🛡️ Anti-Detection & Circuit Breaker

  • Human-like scrolling: Random delays and scroll amounts mimic real user behavior
  • Circuit breaker pattern: Pauses after 3 consecutive failures to prevent bans
  • CAPTCHA detection: Monitors for rate limit messages and challenge pages
  • State recovery: Saves progress to localStorage for session recovery

📊 Memory-Safe Export

  • Chunked processing: Reads 1000 records at a time from IndexedDB
  • Never loads all data: Prevents Out-Of-Memory crashes on large datasets
  • UTF-8 BOM: Prepends \uFEFF for proper Excel character encoding
